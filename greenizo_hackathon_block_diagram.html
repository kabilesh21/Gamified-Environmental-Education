🌱 GREENIZO — Hackathon Technical Block Diagram

Gamified Environmental Education Platform Architecture | B.Tech IT Project

💻 Layer 1: Client Presentation Layer (React 19 SPA)

📱 User Dashboard

Welcome header, streak counter, progress gauge ring, recent activity feed.

📚 Learning Modules

Self-paced courses, interactive lesson slides, MCQ quizzes, PDF certificate generation.

🌳 Virtual Eco Garden

Tree growth nurturing (water/fertilize), sunlight trivia, custom garden item placement.

🏆 Leaderboard & Shop

Active user rankings, seasonal event cards, weekly missions, reward item shop catalog.

🔑 Auth Context

React Context API for session management, JWT token storage, route guards.

⬇️ HTTPS / JSON REST APIs ⬇️
🛡️ Layer 2: API Gateway & Security Layer (Spring Security)

🌐 REST Controllers

/api/auth, /api/dashboard, /api/courses, /api/tree, /api/shop, /api/missions.

🔑 JWT Security Filter

Stateless bearer token validation for incoming request authorization headers.

🔒 BCrypt Encoder

Secure password hashing for user registration and authentication handling.

⚠️ Exception Handler

Global @ControllerAdvice mapping runtime exceptions to standard JSON error status.

⬇️ Service Invocations ⬇️
⚙️ Layer 3: Business Logic Layer (Spring Boot Services)

📖 Course & Quiz Engine

Module completion checking, 60% quiz pass validation, badge unlocking, PDF UUID issue.

🌱 Tree & Garden Logic

Tree level progression, coin deduction logic, sunlight trivia timer resets.

🪙 Economy & Shop Service

Eco Coin balance validation, item purchasing, inventory updates, garden placement.

📝 User Activity Logger

Dynamic event logging for completed weekly missions and active seasonal events.

⬇️ Object Relational Mapping (ORM) ⬇️
🗄️ Layer 4: Data & Database Persistence Layer (JPA + MySQL)

⚡ Spring Data JPA

Repository interfaces with automated query methods and Hibernate ORM engine.

👤 User & Auth Tables

users, user_roles, user_activities, user_achievements, user_badges.

📚 Curriculum Tables

courses, lessons, quizzes, quiz_questions, quiz_options, certificates.

🎯 Mission & Event Tables

weekly_missions, user_mission_progress, seasonal_events, shop_items, user_garden_items.
