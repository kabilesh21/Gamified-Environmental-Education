Full System Architecture Block Diagram (Portrait Mode)

💻 1. Frontend Presentation Layer (React 19 SPA + Vite)

📱 Dashboard & Overview

Welcome header, 7-day streak flame, circular progress ring gauge, recent activities log.

📚 Learning & Quiz Module

Self-paced courses, lesson slides, MCQ quizzes (60% pass threshold), PDF certificate generator.

🌳 Virtual Eco Tree & Garden

Tree watering (-5 Coins) & fertilizing (-10 Coins), daily sunlight trivia, garden item grid.

🏆 Gamification & Auth State

Active leaderboards, seasonal events, weekly missions, reward shop, React AuthContext (JWT).

⬇️ HTTPS Requests / RESTful JSON APIs ⬇️
🛡️ 2. Security & API Gateway Layer (Spring Security)

🌐 REST Controllers

/api/auth, /api/dashboard, /api/courses, /api/tree, /api/shop, /api/missions.

🔑 JWT Token Security

Stateless request filter inspecting HTTP Authorization Bearer headers for session validity.

🔒 BCrypt Encryption

One-way hashing algorithm securing user credentials and registration workflows.

⚠️ Global Exception Handler

@ControllerAdvice catching runtime errors and returning structured JSON error payloads.

⬇️ Service Invocations & Logic Execution ⬇️
⚙️ 3. Business Logic Service Layer (Spring Boot Services)

📖 Course & Quiz Service

Calculates quiz scores, unlocks milestone badges, awards XP/Coins, generates UUID certificates.

🌱 Tree Growth & Eco Economy

Tree level progression, coin deduction validation, sunlight trivia timer resets, shop purchases.

📝 User Activity Logger

Dynamic logging service recording completed weekly missions and active seasonal events.

📧 Notification Service

Spring Mail service handling OTP verification emails, password resets, and streak alerts.

⬇️ Object Relational Mapping (Spring Data JPA) ⬇️
🗄️ 4. Data Persistence & Database Layer (JPA + MySQL)

⚡ Spring Data Repositories

Automated repository interfaces handling CRUD operations and Hibernate ORM queries.
